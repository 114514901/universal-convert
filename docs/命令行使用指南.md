# UniversalConvert 命令行使用指南

本文档说明 `UniversalConvert.Cli.exe` 的用法。该工具用于脚本、批处理与 CI 场景，不创建任何窗口。

主程序 `UniversalConvert.App.exe` 仍承担图形界面职责；其 `--convert`、`--customize`、`--open` 参数用于右键菜单与窗口启动，不属于自动化接口。需要可编程调用时，请使用本文档所述的命令行工具。

## 1. 命令概览

```
UniversalConvert.Cli.exe convert <文件...> --to <扩展名> [选项]
UniversalConvert.Cli.exe formats [--input <扩展名>] [--json]
UniversalConvert.Cli.exe plugins [--json]
UniversalConvert.Cli.exe --help
UniversalConvert.Cli.exe --version
```

- `convert`：执行转换。
- `formats`：列出已注册的转换方向。
- `plugins`：列出已加载的插件及其状态。
- `--help`：显示完整帮助。
- `--version`：显示版本。

未提供任何参数时，等同于 `--help`。若安装目录未加入系统 `PATH`，请使用完整路径调用。

## 2. 转换选项

| 选项 | 说明 |
| --- | --- |
| `--to <扩展名>` | 目标格式，必填，例如 `mp3`、`mp4`。前导点可省略。 |
| `--output <文件>` | 单文件转换的输出文件路径。扩展名必须与 `--to` 一致。 |
| `--output-dir <目录>` | 输出目录。目录不存在时自动创建。 |
| `--preset <名称>` | 使用插件声明的预设。名称不区分大小写。 |
| `--plugin <插件 Id>` | 同一转换方向存在多个候选插件时，显式指定插件。 |
| `-O, --option <键=值>` | 覆盖插件参数，可重复使用。键必须在当前格式的参数 schema 中。 |
| `--file-list <文件>` | 从 UTF-8 文本文件读取输入路径，每行一个。 |
| `--force` | 覆盖已存在的输出文件。 |
| `--dry-run` | 仅显示解析结果，不执行转换，也不写入文件。 |
| `--jobs <数量>` | 并行转换数量，范围 1 至 64，默认 1。 |
| `--stop-on-error` | 任一文件失败后不再启动后续文件；已在执行的转换会继续完成。 |
| `--progress <模式>` | 进度显示：`auto`、`always`、`never`，默认 `auto`。 |
| `--json` | 以行分隔 JSON 输出事件。 |
| `--quiet` | 仅输出错误信息。不能与 `--json` 同时使用。 |
| `--verbose` | 输出详细诊断信息。 |

通用约定：

- 选项名不区分大小写。
- 支持 `--name value` 与 `--name=value` 两种写法。
- 使用 `--` 分隔选项与文件路径，以便处理以短横线开头的文件名。
- `--output` 与 `--output-dir` 不能同时使用。
- `--output` 仅适用于单文件转换。
- 所有输入文件与目标格式在开始转换前统一校验；任一输入无法解析时，整批不会开始转换。

## 3. 输出与覆盖规则

1. 默认不覆盖已存在的输出文件。目标文件已存在时，自动使用 `名称 (1).扩展名`、`名称 (2).扩展名`，依此类推。
2. 使用 `--force` 时，转换结果先写入目标目录中的临时文件；转换成功后再替换目标文件。转换失败或取消时，目标文件保持不变。
3. 输出文件不能与输入文件相同。该限制对外部工具与原地编辑均适用。
4. `--output-dir` 指定的目录不存在时自动创建；`--dry-run` 不创建目录。
5. 多个输入文件解析到同一输出路径时：
   - 未使用 `--force`：按第 1 条依次追加序号；
   - 使用 `--force`：直接报错，避免并发覆盖。
6. 临时文件在转换结束、失败或取消后清理。

## 4. 插件选择

同一「输入扩展名 → 输出扩展名」方向可能由多个插件注册。命令行按以下顺序确定插件：

1. `--plugin` 显式指定的插件；
2. 图形界面中记住的格式选择（设置键 `formatChoice.<输入>.<输出>`）；
3. 唯一候选；
4. 以上均无法确定时，报错并列出候选插件。

命令行不会弹出选择窗口。需要交互选择时，请使用图形界面，或在命令中指定 `--plugin`。

## 5. 预设与参数

参数合并顺序为：插件默认值 → 预设覆盖 → `--option` 覆盖。

- 预设名称不区分大小写；命中后使用插件声明的规范名称。
- `--option` 的键必须在当前格式的参数 schema 中，否则报错并列出可用键。
- 值为空时表示清除该参数，例如 `-O extraArgs=`。
- 参数值中的单位会按插件声明的单位类型归一化，例如 `320 kbps` 归一化为 `320k`、`44.1 kHz` 归一化为 `44100`。

## 6. 退出码

| 退出码 | 含义 |
| --- | --- |
| 0 | 全部成功。 |
| 1 | 转换失败。 |
| 2 | 参数错误。 |
| 3 | 格式不受支持，或无法唯一确定插件。 |
| 4 | 输入文件不存在。 |
| 5 | 所需外部工具不可用。 |
| 6 | 部分文件失败。 |
| 70 | 内部错误。 |
| 130 | 用户取消。 |

在 `--json` 模式下，退出码的含义不变；调用方应同时检查退出码与 `summary` 事件。

## 7. JSON 输出

`convert --json` 采用行分隔 JSON（NDJSON），每行一个事件，写入标准输出。事件类型如下：

| 事件 | 触发时机 | 主要字段 |
| --- | --- | --- |
| `plan` | `--dry-run` 解析完成 | `file`、`output`、`plugin`、`preset`、`overwrite` |
| `start` | 开始处理某个文件 | `file`、`output`、`plugin`、`index`、`total` |
| `progress` | 转换进度更新 | `file`、`index`、`total`、`percent`（可为空）、`stage`、`message` |
| `success` | 单个文件成功 | `file`、`output`、`durationMs` |
| `failure` | 单个文件失败 | `file`、`code`、`message`、`detail`（可选） |
| `skipped` | 文件被跳过 | `file` |
| `warning` | 非致命警告 | `message` |
| `error` | 参数或整体错误 | `message`、`code`（可选） |
| `summary` | 汇总 | `total`、`succeeded`、`failed`、`skipped`、`durationMs` |
| `cancelled` | 用户取消 | 无 |

所有事件均包含 `event` 与 `timestamp`（UTC，ISO 8601）。输出采用 UTF-8；为兼容不同终端，非 ASCII 字符会转义为 Unicode 转义序列。`--dry-run` 的 `summary` 事件使用 `dryRun=true` 与 `planned` 字段，而非转换计数。

`formats --json` 与 `plugins --json` 输出 JSON 数组，而非 NDJSON。

插件加载警告写入标准错误，不混入标准输出的 JSON 数据。

## 8. 示例

```bat
:: 单文件转换为 MP3
UniversalConvert.Cli.exe convert "D:\Media\a.flac" --to mp3

:: 指定输出文件与预设
UniversalConvert.Cli.exe convert "D:\Media\a.flac" --to mp3 --output "D:\Output\a.mp3" --preset "320 kbps"

:: 批量转换并覆盖同名输出
UniversalConvert.Cli.exe convert "D:\Media\a.mp4" "D:\Media\b.mkv" --to mp4 --output-dir "D:\Output" --force

:: 并行转换，失败即停止启动后续文件
UniversalConvert.Cli.exe convert --file-list "D:\Media\list.txt" --to mp3 --output-dir "D:\Output" --jobs 4 --stop-on-error

:: 仅查看解析结果
UniversalConvert.Cli.exe convert "D:\Media\a.mp4" --to mp3 --dry-run --verbose

:: 机器可读输出
UniversalConvert.Cli.exe convert "D:\Media\a.mp4" --to mp4 --json

:: 列出 MP4 的目标格式
UniversalConvert.Cli.exe formats --input mp4

:: 列出插件
UniversalConvert.Cli.exe plugins
```

## 9. 配置、插件与工具

- 配置读取自 `%AppData%\UniversalConvert\config.json`，与图形界面共用。
- 命令行程序将自身所在目录视为安装目录，并从 `{安装目录}\plugins` 加载内置插件。
- 用户扩展从 `%AppData%\UniversalConvert\plugins` 加载；同一插件 Id 时，用户目录优先。
- 外部工具查找顺序：
  1. 插件自身目录下的 `tools\{工具名}.exe`；
  2. `config.json` 中 `ToolPaths` 显式配置的路径；
  3. 安装目录下的 `tools\{工具名}.exe`。
- 出于安全考虑，命令行不读取系统 `PATH`。如需使用特定版本的工具，请放入安装目录的 `tools`，或在 `ToolPaths` 中显式配置。
- 上述工具查找顺序适用于继承 `ExternalToolConverterBase` 的插件；直接实现 `IConverterPlugin` 并调用 `IPluginContext.FindTool` 的插件只使用后两项。
- 运行日志写入 `%AppData%\UniversalConvert\logs\cli.log`。

## 10. 与图形界面的差异

| 能力 | `UniversalConvert.App.exe` | `UniversalConvert.Cli.exe` |
| --- | --- | --- |
| 运行方式 | 图形界面 | 无窗口控制台 |
| 转换结果 | 窗口展示，需用户关闭 | 标准输出与退出码 |
| 多插件歧义 | 弹出选择窗口 | 报错，需 `--plugin` |
| 覆盖控制 | 自动追加序号 | 默认追加序号，`--force` 覆盖 |
| 暂停/继续 | 支持 | 不支持 |
| 并行数量 | 读取设置 | `--jobs` |
| 进度 | 图形进度条 | 文本或 NDJSON |
| 适用场景 | 日常交互 | 脚本、批处理、CI |

## 11. 已知限制

- 仅支持 Windows 与 .NET Framework 4.8。
- 不支持从标准输入读取文件列表；请使用 `--file-list`。
- 不支持递归遍历目录；请由调用方生成文件列表。
- 不支持暂停与继续；取消使用 Ctrl+C。
- 多文件并行时，文本进度可能交错；需要稳定的机器接口时请使用 `--json`。
- 预设与参数覆盖以插件声明的 schema 为准；schema 未声明的参数不能通过 `--option` 传入。

## 12. 故障排查

| 现象 | 处理方式 |
| --- | --- |
| 退出码 5，提示工具不可用 | 将工具放入 `{安装目录}\tools`，或在 `config.json` 的 `ToolPaths` 中配置路径。 |
| 退出码 3，提示多个候选插件 | 使用 `--plugin <插件 Id>` 指定；可先运行 `plugins` 查询插件 Id。 |
| 退出码 2，提示预设不存在 | 运行 `formats` 查看目标格式，或使用图形界面确认预设名称。 |
| 输出文件被追加序号 | 默认不覆盖；需要覆盖时使用 `--force`。 |
| 进度显示为空 | 输出被重定向时 `auto` 模式不输出中间进度；使用 `--progress always`。 |
| JSON 解析失败 | 确认使用 UTF-8 读取；每个事件占一行，`detail` 字段可能包含换行转义。 |
