# 文件占用与更新说明

本文档说明 UniversalConvert 在更新主程序或扩展时遇到文件被占用的原因、自动解除机制与手动处理方法。

## 1. 文件为何会被占用

Windows 不允许替换或删除正被其它进程打开的文件。本项目常见占用来源如下：

1. **explorer.exe**：右键菜单扩展会把 `UniversalConvert.ContextMenu.dll`、`UniversalConvert.Core.dll`、`SharpShell.dll` 以及部分用户扩展加载进资源管理器进程。
2. **主程序自身**：.NET Framework 通过 `Assembly.LoadFrom` 加载插件后，插件 DLL 在当前进程生命周期内不能被卸载；主程序也不允许在运行中替换自己已加载的 `UniversalConvert.Core.dll`。
3. **第三方 shell 扩展或桌面整理软件**：部分程序会主动枚举右键菜单并加载相关 DLL。
4. **安全软件或文件索引工具**：扫描、备份或实时防护可能在短时间内持有文件句柄。

关闭文件句柄与结束进程是两件不同的事。关闭句柄不会终止进程，但已映射为映像的 DLL 仍可能受 Windows 映像段限制；此时仍需要重启对应进程或采用暂存更新。

## 2. 自动解除机制

### 2.1 句柄级解除

`UniversalConvert.Core.Process.FileUnlocker` 使用与系统工具相同的思路：

1. 通过 Restart Manager 查询占用目标文件的进程。
2. 枚举这些进程的句柄，仅筛选对象类型为 `File` 且对象路径与目标文件完全匹配的句柄。
3. 通过 `DuplicateHandle(..., DUPLICATE_CLOSE_SOURCE)` 关闭该文件句柄。

默认策略 `Safe` 只处理 `explorer.exe`、本产品的 App/CLI/ContextMenu/Installer 进程；`All` 策略可处理其它可访问的非系统关键进程。两种策略都**不结束进程**，也不会关闭与目标文件无关的句柄。

该机制用于扩展暂存更新前的占用解除、暂存卸载与旧版扩展目录迁移，以及主程序更新启动安装器前关闭资源管理器等进程对安装目录文件的句柄。

### 2.2 暂存更新

当前进程已加载的插件 DLL 无法安全卸载，因此运行中的扩展更新仍会先写入 `pending` 暂存目录，并在下次启动、插件加载前应用。启动时会先尝试句柄级解除，再替换目标目录；仍失败则保留暂存内容，下次启动重试。

### 2.3 主程序更新

主程序更新需要替换自身已加载的 `UniversalConvert.Core.dll` 等文件，必须在应用退出后完成。更新器会先关闭资源管理器等进程的文件句柄，再启动安装器；安装器使用 `/FORCECLOSEAPPLICATIONS` 关闭仍占用待更新文件的进程，避免出现“跳过文件”后版本混用。

## 3. 边界与限制

- 当前进程自身加载的程序集不能在本进程内替换；必须退出应用。
- 受保护进程、更高完整性级别进程或系统进程可能无法打开，无法关闭其句柄；程序会记录剩余占用进程并保留暂存。
- 关闭句柄不等于卸载 DLL；若 Windows 仍持有映像段，替换会继续失败，此时应重启应用或资源管理器。
- 不建议在转换任务运行期间执行更新；请等待任务结束。

## 4. 版本不一致的修复

若命令行提示 `UniversalConvert.Core.dll` 版本不一致或出现 `MissingMethodException`，通常表示安装时文件被占用并选择了“跳过”。请按以下步骤处理：

1. 关闭 UniversalConvert 主程序与所有命令行窗口。
2. 重新运行对应版本的 `UniversalConvert-Setup.exe`；如仍提示文件占用，使用 `UniversalConvert-Setup.exe /FORCECLOSEAPPLICATIONS`。
3. 安装过程中不要选择“跳过”待更新文件。
4. 安装完成后核对版本：

```powershell
Get-Item "F:\UniversalConvert\UniversalConvert.Cli.exe",
         "F:\UniversalConvert\UniversalConvert.Core.dll" |
  Select-Object Name, @{n='ProductVersion';e={$_.VersionInfo.ProductVersion}}
```

两行 ProductVersion 应一致（例如均为 `2.9.0-dev.5`）。

5. 若仍无法替换，可重启 Windows 后重新安装，或卸载后安装到新目录（用户配置与扩展位于 `%AppData%\UniversalConvert`，卸载时可按提示保留）。

## 5. 设计取舍

句柄级解除优先于结束进程：它可以解决大部分资源管理器、桌面整理软件和短时扫描造成的占用，同时避免丢失其它程序的数据。对于本产品当前进程已加载的程序集，重启是唯一安全的替换方式；因此扩展更新仍保留暂存机制，主程序更新仍要求应用退出。
